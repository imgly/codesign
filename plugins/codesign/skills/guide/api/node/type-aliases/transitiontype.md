```ts
type TransitionType = 
  | TransitionTypeShorthand
  | TransitionTypeLonghand;
```

The block type IDs for the transition blocks. These are the IDs used to create new transitions
using `cesdk.engine.block.createTransition(id)`.
Refer to [TransitionTypeShorthand](./api/node/type-aliases/transitiontypeshorthand.md) and [TransitionTypeLonghand](./api/node/type-aliases/transitiontypelonghand.md) for more details.
