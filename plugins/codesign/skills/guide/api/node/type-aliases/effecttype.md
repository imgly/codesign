```ts
type EffectType = 
  | EffectTypeShorthand
  | EffectTypeLonghand;
```

The block type IDs for the effect blocks. These are the IDs used to create new effects
using `cesdk.engine.block.createEffect(id)`.
Refer to [EffectTypeShorthand](./api/node/type-aliases/effecttypeshorthand.md) and [EffectTypeLonghand](./api/node/type-aliases/effecttypelonghand.md) for more details.
