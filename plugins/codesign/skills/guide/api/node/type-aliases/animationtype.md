```ts
type AnimationType = 
  | AnimationTypeShorthand
  | AnimationTypeLonghand;
```

The block type IDs for the animation blocks. These are the IDs used to create new animations
using `cesdk.engine.block.createAnimation(id)`.
Refer to [AnimationTypeShorthand](./api/node/type-aliases/animationtypeshorthand.md) and [AnimationTypeLonghand](./api/node/type-aliases/animationtypelonghand.md) for more details.
