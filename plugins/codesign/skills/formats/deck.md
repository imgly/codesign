# deck — presentation slides

- **Size:** 1920 × 1080 px per slide
- **Aspect:** 16:9
- **Medium:** screen
- **Structure:** one page per slide

## Notes

- Slide count derives from talk length: **≈ 1.5 × minutes, clamped to 5–30** (a ~10 min talk →
  ~15 slides). The `create` skill's deck intake asks for the length.
- Every slide shares one grid, one type scale, and one palette — the design-rules composition
  and hierarchy sections (handbook §6.4, §6.3) apply per slide.
- Projector/screen viewing: keep body text comfortably above the web minimums; slides read at a
  distance.
