# tiktok — TikTok video

- **Size:** 1080 × 1920 px
- **Aspect:** 9:16 (tall)
- **Medium:** screen (video)

## Safe zones

Platform UI overlays the edges — keep primary content, captions and CTAs clear of:

- **Top ~150 px** — Following / For You tabs, search.
- **Bottom ~420 px** — caption, username, sound ticker.
- **Right ~140 px** — like / comment / share / profile column.

UI placement shifts between app versions; treat these as minimums.

## Notes

- Same canvas as `ig-story` with a taller bottom band and a right-hand column: an ig-story layout
  that sits right against its bottom band is under TikTok's caption here.
- Burned-in captions sit above the bottom band, left-aligned or centered within the width that
  clears the right column.
