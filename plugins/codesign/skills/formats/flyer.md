# flyer

- **Print sizes:** A5 148 × 210 mm (default) · A4 210 × 297 mm · DL 99 × 210 mm — each +
  **3 mm bleed**
- **Medium:** print
- **Structure:** two-sided → one page per side

## Print rules

- ≥300 dpi; fonts embedded/outlined; text inside the **~8% safe margin**, out of the bleed
  (handbook §6.1.10, §6.4).
- Print minimum type sizes apply: body 9–12 pt, caption ≥7 pt (handbook §6.1.2).

## Notes

- Hand-held reading distance — denser than a poster, but the hierarchy chain (handbook §6.3)
  still needs one dominant element per side.
- DL is a tall narrow column: short measure, stacked composition.
